# Exploratory MCP

Connect an AI app to Exploratory through MCP. There are two sides, and the first thing to decide is which one you need.

| | Server | Desktop |
| --- | --- | --- |
| What it works on | Content you published to exploratory.io (notes, dashboards, charts, analytics and data) | The projects in Exploratory Desktop on your computer, including changes you have not published |
| What it does | Reads. It cannot create, edit, publish or delete | Creates and edits: data frames, wrangling steps, charts, analytics, notes and dashboards |
| Where you set it up | In your AI app, with the server URL and a sign-in in your browser | In Exploratory Desktop, System Settings, with the plugin installation card |

- [Server](server/server.md) - Read content published on exploratory.io.
- [Desktop](desktop/desktop.md) - Create and edit projects in Exploratory Desktop on your computer.
