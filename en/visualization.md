In the Chart view, you assign columns to a chart type and configure it with features such as color, axes, layout and reference lines. This section lists the chart types and the features that apply to them.


## Chart types

- [Pivot Table](/en/viz/pivot) - Summarize (aggregate) data and spot outliers or patterns quickly by using color.
- [Summarize Table](/en/viz/summarize-table) - Group rows by one or more columns and summarize their values.
- [Table](/en/viz/table) - View the raw data quickly.
- [Bar Chart](/en/viz/bar) - Display values as vertical or horizontal bars.
- [Line Chart](/en/viz/line) - Plot values along an X-axis, with optional aggregation for dates.
- [Area Chart](/en/viz/area) - Plot values as an area, with optional date or numeric aggregation.
- [Pie / Ring Chart](/en/viz/pie) - Visualize the ratio of the data in pie or ring shapes.
- [Radar Chart](/en/viz/radar) - Compare values from at least three columns on a radar chart.
- [Histogram Chart](/en/viz/hist) - Show the distribution of a numeric column.
- [Density Plot](/en/viz/densityplot) - Show the distribution of the data by curved lines.
- [Scatter (No Aggregation) Chart](/en/viz/scatter) - Plot observations on X and Y axes without aggregating them.
- [Scatter (With Aggregation) Chart](/en/viz/bubble) - Plot one bubble per group using aggregated X and Y values.
- [Boxplot Chart](/en/viz/boxplot) - Show the distribution of a value and choose whether to include outliers.
- [Violin Chart](/en/viz/violin) - Show the distribution of the data with violin-like shapes.
- [Error Bar Chart](/en/viz/errbar) - Display error bars for means or ratios.
- [Error Bar (Summarized Data) Chart](/en/viz/errbar-agg) - Create an Error Bar from data that is already summarized.
- [Map - Standard](/en/viz/easymap) - Plot regions such as countries, US states, or Japanese prefectures.
- [Map - Extension](/en/viz/geojson) - Install a GeoJSON map extension from the visualization view.
- [Map - Long / Lat](/en/viz/map) - Visualize geographical information on a map with longitude and latitude.
- [Map - Heatmap](/en/viz/maphmap) - Show a heatmap on a map when you have many location data points.
- [Heatmap](/en/viz/heatmap) - Place discrete values on the X and Y axes of a heatmap.
- [Contour](/en/viz/contour) - Use continuous numeric columns for the X and Y axes of a contour plot.
- [Number Chart](/en/viz/singlevalue) - Show a single aggregated number.
- [Word Cloud](/en/viz/wordcloud) - Plot words and use another column to set their size.
- [Custom (R)](/en/viz/r-custom) - Documentation for custom R charts is coming soon.

## Chart features

- [Trend Line](/en/viz/trend-line) - Draw trend or smooth lines on Line and Scatter charts.
- [Reference Line](/en/viz/reference-line) - See which charts and axes support reference lines.
- [Repeat By](/en/viz/small-multiple) - Show multiple charts by groups at a time on the same chart area.
- [Window (Table) Calculation](/en/viz/window-calc) - Available on Pivot, Summarize Table, Bar, Line, and Area charts.
- [Date / Time Aggregation](/en/viz/date-aggregate) - Choose how date and time values are aggregated.
- [Range](/en/viz/range) - Show additional range information on a chart.
- [Marker Type](/en/viz/marker) - Change the marker type for each Y-Axis.
- [Multiple Y-Axis](/en/viz/multi-y) - Assign multiple columns to Y-Axis.
- [Configure Layout and Format](/en/viz/layout) - Configure the layout and format of the chart such as margins, font size and title.
- [Select and Configure Columns](/en/viz/column-configuration) - Configure which columns to show and how each column shows.
- [Column Configuration Dialog](/en/viz/column-configuration-dialog) - Change the format of the target column.
- [Color & Group Setting](/en/viz/color) - Update the color and grouping settings.
- [Color setting](/en/viz/color-dialog) - Update the color setting from the Color setting dialog.
- [User Color Palette](/en/viz/custom-palette) - Create your own color palette.
- [Chart Pinning](/en/viz/pin) - Pin the chart to the currently selected data transformation step.
- [Save Chart as PNG / SVG](/en/viz/save) - Export the chart in PNG or SVG format.
- [Export Chart as EDF (Exploratory Data File)](/en/viz/save-as-edf) - Export the chart as EDF, which includes the chart configuration and the data reproducing steps.
- [Share / Schedule](/en/viz/schedule) - Share and schedule your data and charts by publishing to exploratory.io.
- [URL Link](/en/viz/urllink) - Make the value text a URL link built dynamically from the data.
- [Category (Binning)](/en/viz/category) - Categorize numeric values inside the chart.
- [Highlight](/en/viz/highlight) - Change the color of specific markers such as bars, lines or circles to stand out.
- [Limit Values](/en/viz/limit) - Limit or filter the output of the categorical values by conditions.
- ['Others' Group](/en/viz/others-group) - Reduce the number of categories by changing some category names to 'Others'.
- [Edit Display Names](/en/viz/edit-display-name) - Edit the display name of the values on the chart.
- [Missing Value Handling](/en/viz/missing-value-handling) - See which chart types support missing value handling.
- [Rename Column Names](/en/viz/rename-column-names) - Edit the display name of the column names.
- [Axis Setting](/en/viz/dualy-setting) - Change axis configurations.
- [Axis Formatting](/en/viz/axis-format) - Configure how to show the axis.
- [Show Detail](/en/viz/show-detail) - Show the detailed data underlying the chart.
- [Fit to Screen](/en/viz/table-fit-to-screen) - Fit the table to the chart viewing area.
- [Number of Unique Values Check](/en/viz/number-of-unuque-values-check) - Choose how to handle a chart column with many distinct values.
