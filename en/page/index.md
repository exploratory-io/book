An Exploratory Page (Page) is a web page that an AI tool such as Claude creates and publishes on exploratory.io. You can make a dashboard, an analysis report or slides as one page that opens in a browser.

## What you can do with Pages

- **Create one by describing it:** Tell your AI tool the name of the data published on exploratory.io and what you want to see. The AI tool builds the page, publishes it as a Page and returns its URL.
- **See the latest data every time:** A Page reads its data each time it opens. When the data is updated, the numbers on the Page change too.
- **Filter and switch views:** A Page can be interactive, for example filtering when you click a bar in a chart.
- **Keep the same URL when you change it:** When you ask the AI tool for a change, the Page gets a new version at the same URL. Earlier versions are kept, and you can restore them.

A new Page is private. Only the person who made it can share it.

## What you need

- An AI tool connected to Exploratory Server MCP (Claude, ChatGPT, Cursor and others). See [Add from an AI tool](/en/mcp/server/clients/apps).
- Data published on exploratory.io
