---
title: "Machine Learning"
---

Build and evaluate models, make predictions from a fitted model, or detect anomalies in a time series.


## Build models

- [Linear Regression Model](/en/ml/linear-regression) - Model a linear relationship between predictors and a response.
- [Logistic Regression Model](/en/ml/logistic-regression) - Fit a model for a response with two possible values.
- [Generalized Linear Regression Model](/en/ml/glm) - A generalized version of linear regression.
- [Multinomial Logistic Regression Model](/en/ml/multinom) - Fit a model for a response with multiple categories.
- [K-means Clustering Model](/en/ml/kmeans) - Cluster data by the K-means algorithm.
- [Random Forest Model](/en/ml/random-forest) - Create a random forest model for regression, binary classification and multiclass classification.
- [XGBoost - Extreme Gradient Boosting](/en/ml/xgboost) - Create an extreme gradient boosting model for regression, binary classification and multiclass classification.
- [Time Series Forecasting](/en/ml/forecasting) - Calculate forecast data into the future from time series data.
- [Time Series Clustering](/en/ml/timeseries_clustering) - Cluster multiple time series data into groups.
- [Anomaly Detection](/en/ml/anomaly) - Detect anomalies in a time series data frame.
- [Calculate Survival Curve](/en/ml/survival-curv) - Calculate a survival curve from survival time and survival status.
- [Survival Analysis - Cox Regression / Proportional Hazard](/en/ml/cox-regression) - Predict how particular types of subjects survive over time, based on past survival data.
- [Market Basket Analysis - Association Rules](/en/ml/arules) - Find rules of what tends to occur at the same time from transaction data.
- [Causal Impact Analysis](/en/ml/causal_impact) - Estimate the impact of an event on a market by using other markets.

## Evaluate predictions

- [Evaluate Prediction - Regression](/en/ml/evaluate_regression) - Return evaluation scores of regression.
- [Evaluate Prediction - Binary](/en/ml/evaluate_binary) - Return evaluation scores of binary classification.
- [Calculate ROC](/en/ml/do_roc) - Return the coordinates of the ROC curve.
- [Evaluate Prediction - Multiclass](/en/ml/evaluate_multi) - Return evaluation scores of multiclass classification.

## Predict

- [Predict Data](/en/ml/prediction) - Use a fitted model to predict values for training data, test data, or another data frame.
- [Predict Data - Binary](/en/ml/prediction_binary) - Choose the threshold used to assign a predicted class.
- [Predict Data - Survival](/en/ml/prediction_coxph) - Predict with a survival model.
- [Simulate Survival Curve](/en/ml/prediction_survfit) - Simulate a survival curve for a cohort with a survival model.

## Inspect a model

- [Summary of Fit](/en/ml/model_stats) - Extract a summary of fit from the model view.
- [Extract Parameter Estimates](/en/ml/model_coef) - Extract model coefficients and optionally calculate their confidence intervals.
- [Run ANOVA Test](/en/ml/model_anova) - Run an ANOVA test from the model view.

## Prepare data

- [Fix Imbalanced Data](/en/wrangling/smote) - Fix imbalanced data by synthesizing minority data with SMOTE.
