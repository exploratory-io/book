## What is sent and recorded

expl sends no usage analytics of its own. It talks only to Exploratory Desktop on your computer and to the Exploratory Server you sign in to.

For tokens, the data access log, server logs and errors, see [What Exploratory Server records](/en/mcp/server/data#records). The [API keys](/en/cli/server/token#records) and [Sign in](/en/cli/server/login#records) pages also describe the API key and login records. For what Desktop records, see [What Desktop records](/en/cli/desktop/data#records).

For whose permissions it uses, see [Data and permissions](/en/mcp/server/data) of MCP Server.
