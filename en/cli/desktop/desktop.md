expl operates the Exploratory Desktop running on this computer, from your terminal.

<a id="target"></a>

## What this is for

> Every command on this page starts with expl and works on the Exploratory Desktop running on this computer. There is no sign-in step: it works when Desktop is running, you are signed in, and you have turned on the CLI in System Settings > MCP / CLI and saved.
>
> To read content on exploratory.io, see [Server commands](../server/server.md). To do the same from an AI tool, see [MCP Desktop](../../mcp/desktop/desktop.md). To read content published on exploratory.io from an AI tool, see [MCP Server](../../mcp/server/server.md).

<a id="difference"></a>

## How it differs from Server

Server commands (expl server) read published content. Desktop commands can also create, change and publish.

An operation that is hard to undo asks for confirmation before it runs.

For how confirmation works and how to avoid waiting, see [Confirmation and long-running operations](guides/confirmation.md).
