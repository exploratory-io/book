---
title: "Cloud Apps Data"
---

You can import data from cloud apps and web services. Some services need a connection or an API key first.

- [Connections for Cloud Apps](/en/import/connection-cloud-apps) - How to set up OAuth connections for cloud apps.
- [FRED (Federal Reserve of Economic Data) Data Import](/en/import/fred) - Import economic data from FRED using an API key.
- [Github Issue Data Import](/en/import/github) - Import issue data from GitHub.
- [Google Analytics Data](/en/import/google-analytics) - Connect to Google Analytics with OAuth and select the data to import.
- [Google Spreadsheet Data Import](/en/import/google-sheet) - Import Google Spreadsheet data.
- [Salesforce Data Import](/en/import/salesforce) - Import data from your Salesforce.
- [Import Twitter Search API data](/en/import/twitter) - The Twitter Search data source is currently unsupported in Exploratory Desktop.
- [Import Stripe API Data](/en/import/stripe) - Get your payment data from Stripe.
- [Weather Data Import](/en/import/weather) - Import historical weather data.
- [Stock Price Data](/en/import/stock-price) - Import historical stock price data.
- [Reinfolib](/en/import/reinfolib) - Documentation for this data source is coming soon.
- [Estat](/en/import/estat) - Documentation for this data source is coming soon.
- [Edinet](/en/import/edinet) - Documentation for this data source is coming soon.
- [API](/en/import/api) - Documentation for this data source is coming soon.
