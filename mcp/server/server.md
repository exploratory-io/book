# Exploratory MCP: Server

Read notes, dashboards, charts, analytics and data published on exploratory.io from an AI client. It is read-only: it reads what you already published and what you can view.

- [Overview and server URL](overview.md) - What it does, the server URL and how it signs in.
- [Add from an AI tool](clients/apps.md) - Steps for the Claude app, ChatGPT app, Antigravity, Grok Bot, Claude Code, Codex, Cursor and other clients.
- [Authentication and API keys](auth.md) - The browser sign-in, and how to connect with an API key.
- [Use](examples.md) - What you can ask the AI.
- [Tools](tools.md) - What the AI can use.
- [Limits and errors](limits.md) - Rate limits and what to do about errors.
- [Data and permissions](data.md) - Whose permissions it uses and what Exploratory records.
- [Troubleshooting](troubleshooting.md) - Find what to do from a symptom.

To create and edit projects in Exploratory Desktop on your computer, use the [Desktop MCP](../desktop/desktop.md) instead.
