# Exploratory MCP: Server

AI クライアントから、exploratory.io にパブリッシュされたノート、ダッシュボード、チャート、アナリティクス、データを読み取ります。読み取り専用で、公開済みの内容のうち、あなたが閲覧できるものを読みます。

- [概要と接続先 URL](overview_ja.md) - できること、サーバー URL、サインインの方法です。
- [AI ツールから追加する](clients/apps_ja.md) - Claude アプリ、ChatGPT アプリ、Antigravity、Grok Bot、Claude Code、Codex、Cursor、そのほかのアプリの手順です。
- [認証と API キー](auth_ja.md) - ブラウザでのサインインと、API キーでの接続です。
- [使い方の例](examples_ja.md) - AI に頼めることの例です。
- [使える道具](tools_ja.md) - AI が使える操作です。
- [制限とエラー](limits_ja.md) - 回数の上限とエラーの対処です。
- [データと権限](data_ja.md) - どの権限で動作するか、Exploratory が何を記録するかです。
- [トラブルシューティング](troubleshooting_ja.md) - 症状から対処を探します。

あなたのコンピューターの Exploratory Desktop でプロジェクトを作り、編集するときは、[Desktop の MCP](../desktop/desktop_ja.md) を使います。
