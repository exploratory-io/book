# AI ツールから追加する

すでにお使いの AI アプリに、Exploratory のサーバーを追加します。どのアプリも、つなぐ先は同じです。初回に、ブラウザで Exploratory にサインインします。

```text
https://exploratory.io/mcp
```

<a id="apps"></a>

## アプリを選ぶ

- [Claude アプリ](claude_ja.md) - Claude に、カスタムコネクタとして追加します
- [ChatGPT アプリ](chatgpt_ja.md) - ChatGPT のデスクトップアプリに、MCP サーバーとして追加します（Web で使う場合の手順も、同じページにあります）
- [Antigravity](antigravity_ja.md) - Antigravity にサーバーを登録します
- [Grok Bot](grok-bot_ja.md) - Grok Bot のチャットでサーバーを追加します
- [Claude Code](claude-code_ja.md) - Claude Code にサーバーを登録します
- [Codex](codex_ja.md) - Codex にサーバーを登録します
- [Cursor](cursor_ja.md) - Cursor にサーバーを登録します
- [そのほかのアプリ](other_ja.md) - Streamable HTTP と OAuth に対応したクライアントです

アプリがブラウザを開けないときは、代わりに API キーで接続します。[API キーで接続する](../overview_ja.md#apikey) を参照してください。
