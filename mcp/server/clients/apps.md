# Add from an app

Add the Exploratory server to an AI app you already use. Every app connects to the same address, and you sign in to Exploratory in your browser the first time.

```text
https://exploratory.io/mcp
```

<a id="apps"></a>

## Choose your app

- [Claude app](claude.md) - Add it as a custom connector from the Claude desktop app
- [ChatGPT app](chatgpt.md) - Add it as an MCP server from the ChatGPT desktop app
- [Antigravity](antigravity.md) - Register the server in Antigravity
- [Grok Bot](grok-bot.md) - Add the server in a Grok Bot chat
- [Claude Code](claude-code.md) - Register the server in Claude Code
- [Codex](codex.md) - Register the server in Codex
- [Cursor](cursor.md) - Register the server in Cursor
- [Other clients](other.md) - Any client that supports Streamable HTTP and OAuth

If your app cannot open a browser, connect with an API key instead. See [Connect with an API key](../overview.md#apikey).
