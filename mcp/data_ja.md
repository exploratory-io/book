# データと権限

どの権限で動作するか、何を読み取るか、Exploratory が何を記録するかを説明します。

<a id="who"></a>

## 実行されるユーザー

Server MCP の呼び出しは、サインインしたユーザーとして実行されます。そのユーザーが exploratory.io で閲覧できる範囲を超えることはありません。読み取るのは、パブリッシュされたコンテンツのみで、読み取り専用です。

<a id="publisher"></a>

## 公開した人ができること

公開した人は、パブリッシュされたコンテンツごとに、MCP からのアクセスを止められます。データの行を非公開にすることもできます。その場合も、要約は共有できます。

<a id="records"></a>

## Exploratory が記録するもの

この MCP サーバーへの呼び出しについて、Exploratory Server は次のものを記録します。コマンドラインの expl server でも同様です。

トークンは、アクセス許可を表す文字列です。ハッシュは、元の文字列をそのまま保存せず照合するための値です。

- トークンと API キー: 平文ではなくハッシュで保存し、作成日時、有効期限、最終使用日時を記録します。トークンは「接続中のAIアプリ」で、API キーはアカウント設定 \> API キーで、確認・失効できます。
- データアクセスログ: アイテム、ユーザー ID とメールアドレス、経路、サインインの方法（ブラウザまたは API キー）と API キーの名前、操作、クライアント名、IP アドレス、結果とエラーコード、処理時間。保持期間は既定で 90 日です（サーバーの設定で 1〜400 日）。
- サーバーのログ: ツールの呼び出しごとの記録（メールアドレス、クライアント、結果、行数、処理時間）と、トークンの作成・削除。
- 失敗した呼び出しのエラー: 時刻、ツールの呼び出し、エラーの内容を、製品の改善のために収集します。

- [Exploratory のプライバシーポリシー](https://exploratory.io/privacy) - データの取り扱いに関する方針を確認します。

<a id="provider"></a>

## AI の提供元へ渡るもの

ツールが返すもの（行、列名、チャートの画像、エラー）は、会話の一部になります。使っている AI の提供元（例: Anthropic、OpenAI、Google、xAI）へ、その提供元の規約のもとで送られます。その提供元へ送ってはいけないデータには、この接続を使わないでください。

<a id="disconnect"></a>

## 接続を解除する

Server MCP の接続を解除するときは、exploratory.io のアカウント設定の「接続中のAIアプリ」から、クライアントを解除します。クライアントの設定から登録を削除しただけでは、アクセスの許可は残ります。 API キーを止めるには、同じアカウント設定の「API キー」で取り消します。

- [クライアントを選ぶ](server_ja.md) - クライアントごとの、登録を解除する手順です。
