# リファレンス

道具、制限、エラー、権限について、調べたいことからページを探します。

| 調べたいこと | ページ |
| --- | --- |
| AI が使える道具と、「作成、変更、削除を許可する」が必要なもの | [使える道具](tools_ja.md) |
| Desktop が拒否するもの、止めるものと、その対処 | [制限とエラー](limits_ja.md) |
| 何が送られ、何が記録されるか | [データと権限](data_ja.md) |
| 症状からの対処 | [トラブルシューティング](troubleshooting_ja.md) |

つなぎ方は、[はじめる](get-started_ja.md)を参照してください。Desktop で決められること（確認、データの範囲、プラグインの設定）は[許可の範囲と設定](permissions_ja.md)、プラグインのインストール、更新、削除は[プラグインのインストール](install_ja.md)にあります。

ターミナルのコマンドを調べるときは、CLI Desktop の[リファレンス](../../cli/desktop/reference_ja.md)を参照してください。
