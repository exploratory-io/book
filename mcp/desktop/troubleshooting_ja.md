# トラブルシューティング（Desktop）

Desktop MCP で表示されるメッセージと、その対処です。

<a id="check"></a>

## まず状態を確かめる

接続できているかを、[AI ツールで確かめる](install_ja.md#steps)の手順で確かめます。つながらないときは、下の表で、表示された内容を探します。

<a id="contact"></a>

## 問い合わせるとき

support@exploratory.io へ、次を送ってください。Exploratory Desktop のバージョン、AI クライアントの名前とバージョン、行った操作、表示されたエラーの文です。トークンや API キーは伏せてください。

<a id="trouble"></a>

## トラブルシューティング

| 表示される内容 | 対処 |
| --- | --- |
| exploratory-mcp が見つからない | MCP をオンにした Exploratory Desktop v17 以降を起動します。コマンドはアプリの起動時に自動で入ります。そのあと、AI クライアントを起動し直します。 |
| AI クライアントから exploratory-mcp が見つからない（macOS） | Exploratory をディスクイメージから開いています。アプリケーションフォルダに移して起動し直すと、起動時にコマンドが入ります。 |
| Desktop の MCP のツールが、起動していないというエラーを返す | Exploratory Desktop を起動します。そのあと、同じ会話で、もう一度ツールを使います。 |
| MCP がオフだと表示される | システム設定 \> MCP / CLI で、「MCP」のスイッチをオンにします。そのあと、システム設定の下にある「保存」を選びます。 |
| カードに「インストールできませんでした。」と表示される | 「詳細」にマウスを載せて、出力を確かめます。理由の文に従って直し、「もう一度試す」を選びます。詳しくは [プラグインのインストール](install_ja.md#failure) を参照してください。 |
| 別の場所から登録された exploratory があります（…）。「…」で削除してから、もう一度「インストール」を押してください。 | メッセージに出ているコマンドで削除してから、もう一度「インストール」を選びます。 |
| 組織の設定で、このマーケットプレイスが許可されていない可能性があります。管理者に確認してください。 | 管理者に確認します。 |
| Claude Code のフックで node が見つからない | Node.js を入れて、node を PATH に通します。 |
| `計画の関所: R の作業の後は、先にシナリオ（<題名>_シナリオ.md）と計画（<題名>_Exploratory作成計画.md）を保存してください。` | R の作業をしたあとで、作成の操作を、計画の関所が止めています。メッセージに示されたシナリオと作成計画を保存してから続けるよう、AI に頼みます。確認をやめるときは、`plan_gate` を `"false"` にします。[プラグインの設定](limits_ja.md#plugin-settings)を参照してください。 |
| `計画の関所: この計画は記録されません。計画に、実在する HTML のファイル名が書かれていません。` | HTML レポートを保存したのに、計画にその名前がありません。保存した HTML のファイル名を計画に書いて、計画を保存し直します。 |
| `ノートの関所: 次の分析の出力をノートの本文に {{analytics:ID\|出力}} で入れてから作り直してください。` | ノートの作成や本文の置き換えを、ノートの関所が止めています。このセッションで作った予測モデルやクラスタに、ノートの本文に入っていない出力があります。メッセージに挙がった出力を本文に入れてから、もう一度作るよう、AI に頼みます。止めるのは最大 2 回までです。 |
| Desktop の MCP が想定どおりに動かない | Exploratory Desktop にサインインしているかを確認します。 |
