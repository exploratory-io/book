# はじめる

Desktop MCP のプラグインを入れ、Exploratory Desktop で MCP をオンにして、AI ツールにプロジェクトのデータを見せます。所要時間は 5 分ほどで、手順はこのページ 1 つで進められます。同じコンピューターに、Exploratory Desktop と、プラグインを入れる AI ツール（Claude Code、Codex、Antigravity、Cursor のいずれか）を用意してください。

<a id="steps"></a>

## 手順

### 1. プラグインをインストールする

Exploratory Desktop で、画面の左下にある自分の名前を選び、開いたメニューで「システム設定」を選びます。左のメニューで MCP / CLI を選び、「Exploratory Desktop プラグインのインストール」のカードで、使う AI ツールの行の「インストール」を選びます。写真と、手作業で入れる手順は、[プラグインのインストール](install_ja.md)にあります。

### 2. MCP をオンにする

同じ画面で、MCP のスイッチをオンにします。初期状態ではオフです。AI にチャート、ノートなどの作成や変更もさせたいときだけ、「作成、変更、削除を許可する」にもチェックを入れます。そして、画面の下の「保存」を選びます。

保存しないと、MCP のスイッチと「作成、変更、削除を許可する」の設定は効きません。ここでほかに決められることは、[許可の範囲と設定](limits_ja.md)を参照してください。

### 3. AI ツールを再起動して、接続を許可する

インストールした AI ツールを再起動します。AI ツールが初めて接続するときに、Desktop が許可するかどうかを聞きます。自分で起動したアプリだけ許可してください。

### 4. AI にデータを見せる

Exploratory Desktop で、使いたいプロジェクトを開きます。そのうえで、AI ツールで次のように頼みます。

```text
開いている Exploratory のプロジェクトのデータフレームを一覧して
```

読み取りだけの設定でも動きます。作成も試すときは、「作成、変更、削除を許可する」をオンにして保存し、自分のデータの列の棒グラフなど、チャートを頼みます。接続を確かめるには、Claude Code では /mcp を開いて exploratory-desktop が接続済みか確認し、Codex では codex mcp list を実行して exploratory-desktop が一覧にあるか確認します。

<a id="trouble"></a>

## うまくいかないとき

- 呼び出しで MCP がオフと言われる: システム設定に戻り、MCP のスイッチをオンにして「保存」を選んだか確かめます。
- 道具が起動していないというエラーを返す: Exploratory Desktop を起動して、同じ会話で道具をもう一度使います。
- インストールに失敗する: その AI ツールの行に「インストールできませんでした」と出ます。[プラグインのインストール](install_ja.md#failure)の「インストールに失敗したとき」を参照してください。

詳しくは[トラブルシューティング](troubleshooting_ja.md)を参照してください。
