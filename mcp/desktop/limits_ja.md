# 制限とエラー

Desktop の MCP が断る、または止めるものと、その対処です。これらの制限を決める設定は、[許可の範囲と設定](permissions_ja.md)にあります。

<a id="limits"></a>

## 制限

| 表示される内容 | 対処 |
| --- | --- |
| 選んだ範囲を超えるデータの要求が断られる | Desktop が渡すのは、システム設定 \> MCP / CLI で選んだ範囲までです（名前・列・データ型だけ、集計結果、最大 100 行のサンプル、すべての行）。小さい結果を頼むか、範囲を広げます。[Desktop で決められること](permissions_ja.md#control)を参照してください |
| 削除、公開、R コードの実行、AI でのデータ処理などの前に、Desktop が確認を出す | これが確認です。Desktop で承認します。確認をなくすときは、システム設定 \> MCP / CLI の該当する設定をオンにします。[Desktop で決められること](permissions_ja.md#control)を参照してください |
| 新しいアプリの承認を求められる | アプリは、初めて接続するときに承認を求めます。Desktop で承認します。「承認済みのアプリ」でアプリを取り消すと、もう一度求めます。「許可しない」を選んだあと、同じアプリは 5 分間、画面が出ないまま断られます |
| MCP がオフだと表示される | システム設定 \> MCP / CLI で、「MCP」のスイッチをオンにして、システム設定の下にある「保存」を選びます |
| 作成や変更の呼び出しが PERMISSION_DENIED で断られる | 「作成、変更、削除を許可する」がオフです。システム設定 \> MCP / CLI でオンにして、下の「保存」を選びます。読み取りは、オフのままでもできます |
| Desktop の MCP の道具が、起動していないというエラーを返す | Exploratory Desktop を起動します。そのあと、同じ会話で、もう一度道具を使います |

<a id="gates"></a>

## 作成の前の確認で止まるとき

関所は、条件が満たされるまで、作成の操作を止める確認です。AI が直して、続けられます。

| 表示される内容 | 対処 |
| --- | --- |
| `計画の関所: R の作業の後は、先にシナリオ（<題名>_シナリオ.md）と計画（<題名>_Exploratory作成計画.md）を保存してください。` | AI が exploratory-analysis スキルを使って R の作業をしたあとで、作成の操作を、計画の関所が止めています。メッセージに示されたシナリオと作成計画を保存してから続けるよう、AI に頼みます。確認をやめるときは、`plan_gate` を `"false"` にします。[プラグインの設定](permissions_ja.md#plugin-settings)を参照してください。 |
| `計画の関所: この計画は記録されません。計画に、実在する HTML のファイル名が書かれていません。` | HTML レポートを保存したのに、計画にその名前がありません。保存した HTML のファイル名を計画に書いて、計画を保存し直します。 |
| `ノートの関所: 次の分析の出力をノートの本文に {{analytics:ID\|出力}} で入れてから作り直してください。` | ノートの作成や本文の置き換えを、ノートの関所が止めています。このセッションで作った予測モデルやクラスタリングに、ノートの本文に入っていない出力があります。メッセージに挙がった出力を本文に入れてから、もう一度作るよう、AI に頼みます。止めるのは最大 2 回までです。 |
