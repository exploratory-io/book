# 許可の範囲と設定

Desktop で決める設定、確認が入る場面、送られる情報を説明します。

<a id="control"></a>

## Desktop で決められること

システム設定 \> MCP / CLI では、次のことも決められます。

- AI アプリケーションに渡すデータの範囲: 名前・列・データ型だけ、集計結果（チャート、ピボットテーブル）まで、サンプルの行（最大 100 行）まで、すべての行、から選びます。選んだ範囲を超える要求は断られます。
- 承認: 項目の削除（チャート、アナリティクス、ノート、ダッシュボード、ステップ、ブランチ、パラメーター、接続、パレット、テンプレート、R パッケージ、カタログの項目）、ノート・ダッシュボード・データフレーム・プロジェクトの公開と公開の取り消し、接続の保存、データソースの置き換え、プロジェクトの履歴の復元、データフレームの管理、システム設定やカタログのスケジュールの変更の前には、Desktop が先に確認します。R コードの実行、R パッケージの追加、AI でのデータ処理、ノートの AI への質問の前にも確認します。チャート、ノート、ダッシュボードの作成や編集では確認しません。確認なしで実行する設定は、「削除・パブリッシュ・設定の変更を確認なしで実行する」と「コード実行・AI処理を確認なしで実行する」の 2 つにあります。
- 承認済みのアプリ: アプリは、初めて接続するときに、承認を求めます。「取り消す」を選ぶと、そのアプリは、もう一度承認を求めます。

<a id="plugin-settings"></a>

## プラグインの設定（Claude Code）

Desktop のプラグインには、Claude Code で使う設定が 4 つあります。値は、JSON の真偽値ではなく、文字列の `"true"` または `"false"` です。

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| `ai_summary` | `"false"` | 作成したチャートとアナリティクスの AI サマリを、作成して保存します。 |
| `save_comments` | `"false"` | 作成したチャートに、説明のコメントを保存します。 |
| `review_hook` | `"false"` | AI に、作業の見直しをさせます。 |
| `plan_gate` | `"true"` | AI に、作る前に計画を保存させます。[トラブルシューティング](troubleshooting_ja.md#trouble)を参照してください。 |

設定は `claude plugin configure exploratory@exploratory` で確認できます。上のシステム設定 \> MCP / CLI の項目とは別の設定です。

<a id="privacy"></a>

## 送られるものと記録されるもの

- Desktop の MCP は、お使いのコンピューターで動きます。アプリを通して、手元のプロジェクトの内容を読み、編集します。
- ツールが返す内容（行、列名、チャートの画像、エラー）は、会話の一部になります。AI の提供元に、その提供元の規約に従って送られます。その提供元に送ってはいけないデータには使わないでください。
- Exploratory Desktop は、Desktop MCP のツールを 1 回呼び出すたびに、サインインしている exploratory.io のサーバーへ、利用記録を 1 件送ります。記録には、ツールの名前と引数（入力した数式や値が入ることがあります）、成功か失敗か（失敗のときはエラーの種類とメッセージ）、結果の大きさ（内容は含みません）、処理時間、Desktop のバージョン、AI クライアントの名前とバージョン、セッションとアイテムの ID が入ります。送られるのは、サインインしていて、AI 機能がオンのときだけです。ローカルのデータカタログのツールでは送りません。
