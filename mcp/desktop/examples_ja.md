# 使い方の例

Desktop の MCP で、AI に頼めることの例です。どの例も、Exploratory Desktop にプロジェクトを開いて、AI ツールに話しかけます。インストールがまだのときは、先に [プラグインのインストール](install_ja.md) を済ませます。

出力される図や文章は、データと AI ツールによって変わります。例の依頼文は、そのまま使うことも、自分のデータに合わせて言い換えることもできます。

<a id="before"></a>

## 始める前に

- Exploratory Desktop でプロジェクトを開き、システム設定 \> MCP / CLI の「MCP」のスイッチをオンにします。
- チャート、ノート、ダッシュボードなどを作成・変更する例では、「作成、変更、削除を許可する」にもチェックを入れます。オフのときは、読み取りだけができます。
- 設定を変えたら、システム設定の下にある「保存」を選んで保存します。
- 削除、公開、R コードの実行などの前には、Desktop が確認を出します。ただし、確認なしで実行する設定をオンにしていない場合です。以降の例の「確認を出します」も、この条件のときの動きです。詳しくは [許可の範囲と設定](limits_ja.md) を参照してください。

<a id="server-or-desktop"></a>

## Server と Desktop の使い分け

Desktop は、手元のプロジェクト（公開していない変更を含む）を対象にします。exploratory.io に公開した内容を読むときは、[Server の MCP](../server/server_ja.md) を使います。

どちらを使うか決まらない依頼では、プラグインのスキルが、先にどちらを使うかを確かめます。たとえば、exploratory.io のデータから図を作る依頼では、「Exploratory Desktop で作りますか」と聞かれることがあります。最初から、「Exploratory Desktop で」と伝えると、聞かれずに進みます。

<a id="examples"></a>

## 例

### データを読む

```text
開いているプロジェクトの売上データには、どんな列がある？ 地域ごとの件数も教えて
```

列の名前、値の一覧、件数を、データフレームから読みます（データフレームのプレビューやプロファイルの道具）。

### チャートを作る・直す

```text
開いている Exploratory のプロジェクトで、売上データから月別の棒グラフを作って
```

```text
この図を散布図に変えて
```

チャートの作成と変更です（create_chart、update_chart）。作ったチャートは、Exploratory Desktop で開いて確認できます。

### データを加工する

```text
注文日から月の列を作って、地域ごとに売上を集計して
```

列を作る、絞る、集計する、結合するといったデータ加工を、加工のステップとして追加します（create_wrangling_step）。ステップは、Exploratory Desktop の右側のステップに並びます。

### 文章を分類する

```text
自由記述の口コミを、内容ごとに分類する列を作って
```

文章の意味を読んで分類する処理は、AI 関数の列として作ります。決まった規則で変換する処理とは、別のものです。実行の前に、Desktop が確認を出します。

### 統計の分析をする

```text
売上に効く要因を回帰で調べて
```

```text
顧客をクラスタに分けて
```

回帰、検定、クラスタなどのアナリティクスを作ります（create_analytics）。結果は、Exploratory Desktop のアナリティクスとして開けます。

### レポートにまとめる

```text
分析結果をノートにまとめて
```

ノートを書き、保存し、図を埋め込みます（create_note、update_note）。ダッシュボードの更新や、ノート・ダッシュボードの公開（publish_note、publish_dashboard）も頼めますが、公開の前には、Desktop が確認を出します。

### フィルターを付ける

```text
期間を選べるフィルターを付けたい
```

パラメーターを作り、値の一覧を決めて、フィルターや図表に適用します（save_parameter など）。

### データを取り込む

```text
このファイルを取り込んで
```

ファイルやデータベースからデータを取り込み、データソースや接続を作ります（create_data_source、save_connection）。接続の保存の前には、Desktop が確認を出します。
