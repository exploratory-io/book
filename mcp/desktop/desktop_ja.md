# Exploratory MCP: Desktop

AI クライアントから、あなたのコンピューターの Exploratory Desktop で、プロジェクトを作り、編集します。手元のプロジェクトが対象で、公開していない変更も扱えます。

- [概要と必要なもの](overview_ja.md) - できることと、必要なものです。
- [プラグインのインストール](install_ja.md) - Exploratory Desktop のシステム設定からインストールします。1 つのカードで、Claude Code、Codex、Antigravity、Cursor に入れられます。
- [許可の範囲と設定](limits_ja.md) - Desktop で決める設定と、送られる情報です。
- [使い方](examples_ja.md) - AI に頼めることの例です。
- [使える道具](tools_ja.md) - AI が使える操作です。
- [制限とエラー](errors_ja.md) - Desktop の MCP が断る、または止めるものと、その対処です。
- [トラブルシューティング](troubleshooting_ja.md) - 表示されたメッセージから対処を探します。

exploratory.io に公開された内容を読むときは、[Server の MCP](../server/server_ja.md) を使います。
