# Exploratory CLI

Use Exploratory from a terminal with the expl command.

- [CLI Server](server/server.md) - Read content published on exploratory.io.
- [CLI Desktop](desktop/desktop.md) - Work with projects in Exploratory Desktop on your computer.

Read in Japanese: [Server](server/server_ja.md) / [Desktop](desktop/desktop_ja.md)

For first-time use, go to Installation, then Quickstart. For Server, sign in first ([Sign in](server/login.md)).

- Desktop: [Installation](desktop/install.md), [Try it](desktop/quickstart.md)
- Server: [Installation](server/install.md), [Sign in](server/login.md), [Try it](server/quickstart.md)
- Both: [Global flags](desktop/global-flags.md), [Exit codes and errors](desktop/exit-codes.md), updating ([Update](server/install.md#update))
