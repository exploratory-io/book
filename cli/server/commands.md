# All commands

Choose a command by purpose. Open its name to see arguments and examples.

<a id="commands-search"></a>

## Find and read

| Command | Purpose |
| --- | --- |
| [expl server search](search.md) | Search the content you can view by title, description and tags. Without search words, list items newest first. |
| [expl server fetch](fetch.md) | Read one note, dashboard, slide or data item by its id. |

<a id="commands-dataframe-preview"></a>

## Data

| Command | Purpose |
| --- | --- |
| [expl server dataframe get-schema](dataframe-get-schema.md) | Get the columns of a data item, with their types. |
| [expl server dataframe preview](dataframe-preview.md) | Get the rows of a data item, page by page with offset and limit. |
| [expl server dataset query](dataset-query.md) | Filter and aggregate a data item on the server and return only the result. |
| [expl server dataframe export](dataframe-export.md) | Save the result of a query on a data item as a CSV or Parquet file and return a download link. |

<a id="commands-chart-get-data"></a>

## Charts and analytics

| Command | Purpose |
| --- | --- |
| [expl server chart get-data](chart-get-data.md) | Get the data of a chart together with what the numbers mean. |
| [expl server chart get-image](chart-get-image.md) | Get a chart as a PNG image, to see its shape, trend and layout. |
| [expl server analytics get-result](analytics-get-result.md) | Get the result of an analytics (regression, correlation, chi-square test and so on) as structured data. |
| [expl server chart query](chart-query.md) | Filter and aggregate the data of a chart in a note, dashboard or slide on the server and return only the result. |
