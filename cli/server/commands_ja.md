# コマンド一覧

目的からコマンドを選びます。名前を選ぶと、引数と例を確認できます。

<a id="commands-search"></a>

## 探す・読む

| コマンド | できること |
| --- | --- |
| [expl server search](search_ja.md) | 閲覧できるコンテンツを、タイトル、説明、タグで探します。検索語がなければ、新しい順に一覧します。 |
| [expl server fetch](fetch_ja.md) | id を指定して、ノート、ダッシュボード、スライド、データを 1 件読みます。 |

<a id="commands-dataframe-preview"></a>

## データ

| コマンド | できること |
| --- | --- |
| [expl server dataframe preview](dataframe-preview_ja.md) | データの行を、offset と limit でページに分けて取得します。 |
| [expl server dataframe export](dataframe-export_ja.md) | データへの問い合わせの結果を、CSV か Parquet のファイルにして、ダウンロードリンクを返します。 |

<a id="commands-chart-get-data"></a>

## チャートとアナリティクス

| コマンド | できること |
| --- | --- |
| [expl server chart get-data](chart-get-data_ja.md) | チャートのデータを、数値の意味とあわせて取得します。 |
| [expl server chart get-image](chart-get-image_ja.md) | チャートの画像（PNG）を取得します。形、傾向、配置を確認するための機能です。 |
| [expl server analytics get-result](analytics-get-result_ja.md) | アナリティクス（回帰、相関、カイ二乗検定など）の結果を、プログラムで扱える形式のデータで取得します。 |
| [expl server chart query](chart-query_ja.md) | ノート、ダッシュボード、スライドに含まれるチャートのデータを、サーバーで絞り込み、集計して、結果だけを返します。 |
