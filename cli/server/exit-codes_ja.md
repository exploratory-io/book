# 終了コード

expl は、終わるときに終了コードを返します。スクリプトや CI は、この数字で結果を判断できます。

<a id="codes"></a>

## 終了コードの一覧

| コード | 意味 |
| --- | --- |
| 0 | 成功 |
| 1 | 操作が失敗した。Desktop では、確認を断ったときとタイムアウトも含みます。 |
| 2 | 使い方が正しくない。未知のフラグ、読めない JSON、ターミナル以外での --yes 忘れなどです。 |
| 3 | Desktop または Server に接続できない。Server では、ネットワークや HTML のエラーページなどです。 |
| 4 | 認証または権限のエラー。Server では、サインインしていない、またはトークンや API キーが拒否されたとき（間違い、期限切れ、取り消し、管理者による制限）です。 |
| 130 | Ctrl+C で中断した |

出力先のパイプが閉じられた場合（expl ... | head -1 など）は、エラーではなく、終了コード 0 で終了します。

<a id="action"></a>

## 3 と 4 のとき

| コード | 対処 |
| --- | --- |
| 3 | Desktop を使っているときは、Exploratory Desktop を起動して、もう一度実行します。Server を使っているときは、通信を確認して、もう一度実行します。 |
| 4 | Desktop を使っているときは、Exploratory Desktop にサインインします。Server を使っているときは、expl server login を実行します。API キーを使っているときは、間違い・期限切れ・取り消しなら、アカウント設定 \> API キーで新しいキーを作ります。API キーが無効、または IP アドレスが許可されていないというメッセージなら、管理者に確認します。 EXPL_SERVER_TOKEN が設定されていると、保存したログイン情報より先にそちらが使われます。先に unset EXPL_SERVER_TOKEN を実行してください。 |
