# 使い方

公開されたコンテンツを読み、集計するための手順です。

- [データを探す](guides/find-data_ja.md) - 必要なデータを探します。
- [ノートを読む](guides/read-notes_ja.md) - 公開されたノートを読みます。
- [データを集計する](guides/query-data_ja.md) - データを絞り込み、集計します。
- [チャートの数値を取得する](guides/dashboard-charts_ja.md) - チャートの数値を取得します。
- [アナリティクスの結果を取得する](guides/analytics_ja.md) - アナリティクスの結果を取得します。
- [結果をファイルに保存する](guides/export_ja.md) - 結果をファイルに保存します。
- [自動処理](guides/automation_ja.md) - スクリプトや定期ジョブからコマンドを実行します。
- [AI エージェントから使う](guides/agents_ja.md) - AI エージェントにコマンドを実行させます。
