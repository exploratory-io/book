# Exploratory CLI: Desktop

expl は、このコンピューターで起動している Exploratory Desktop を、ターミナルから操作するコマンドです。

<a id="target"></a>

## 対象

> このページのコマンドは、すべて expl で始まり、このコンピューターで起動している Exploratory Desktop を対象にします。サインインの操作はありません。Desktop を起動してサインインし、システム設定 > MCP / CLI で CLI を有効にして保存していれば使えます。
>
> exploratory.io のコンテンツを読むときは、[Server のコマンド](../server/server_ja.md)を参照してください。AI ツールから同じことをするには、[MCP の Desktop](../../mcp/desktop/desktop_ja.md) を参照してください。exploratory.io に公開したコンテンツを AI ツールから読むには、[MCP の Server](../../mcp/server/server_ja.md) を参照してください。

<a id="difference"></a>

## Server との違い

Server のコマンド（expl server）は、公開されたコンテンツを読むためのものです。Desktop のコマンドには、読むだけでなく、作る、変える、公開するものがあります。

取り消しにくい操作は、実行の前に確認します。

確認のしかたと、待たずに済ませる方法は、[確認と時間のかかる操作](guides/confirmation_ja.md)を参照してください。
