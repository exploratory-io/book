データカタログにパブリッシュしたデータは、次の 3 つの方法で使えます。同じデータを、分析する人は Desktop に取り込み、チームはブラウザで確かめ、AI エージェントは質問に使う、というように使い分けられます。

| 使い方 | どこで使うか | できること | ページ |
| --- | --- | --- | --- |
| Desktop へのインポート | Exploratory Desktop | フィルター、列の選択、結合、集計をしてから、データフレームとして取り込む。取り込んだあとは「更新」で最新のデータを読み直せる | [インポート](/ja/data-catalog/import) |
| サーバーの画面 | exploratory.io（ブラウザ） | データを一覧から探し、サマリやテーブル、加工ステップ、アクセスログで中身を確かめる。MCP や API からのアクセスを設定する | [サーバーの画面](/ja/data-catalog/server-ui) |
| AI | Claude などの AI ツール（MCP） | データについて質問し、集計結果を答えてもらう。サーバーのデータを Desktop のプロジェクトに取り込ませる | [AI で活用](/ja/data-catalog/ai) |

## どれを使うか

**自分で分析を続けるなら、Desktop へのインポートを使います。** 必要な行と列だけに絞り、ほかのデータと結合してから取り込めるので、プロジェクトに余計なデータを持ち込まずに済みます。たとえば「全国販売分析」のデータなら、2025 年の EC の注文だけを取り出し、商品マスタと結合して、カテゴリ別・月別の売上として取り込めます。

**チームでデータを共有し、管理するなら、サーバーの画面を使います。** Desktop がなくても、ブラウザでデータの中身や加工の過程を確かめられます。誰がいつデータにアクセスしたかもアクセスログで見られます。

**質問に答えてもらうなら、AI を使います。** 「2025 年の地方別の売上は？」のように聞くと、AI がサーバーでデータを集計し、結果だけを受け取って答えます。承認したセマンティック情報（列の意味や集計のしかた）を AI が読むので、売上を合計するのか平均するのかといった判断を誤りにくくなります。セマンティック情報の作り方は、[セマンティック情報](/ja/data-catalog/semantics)を参照してください。

## 使う前に

どの方法でも、先にデータをデータカタログにパブリッシュしておきます。サーバーの画面と AI で使うには、サーバーへのパブリッシュが必要です。ローカルにだけパブリッシュしたデータは、この PC の Desktop と Desktop MCP から使えます。パブリッシュの手順は、[パブリッシュ](/ja/data-catalog/publish)を参照してください。
