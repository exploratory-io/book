---
title: "Exploratory MCP"
---

MCP を通じて、AI アプリから Exploratory に接続します。接続先は 2 つあります。最初に、どちらが必要かを決めます。

| | Server | Desktop |
| --- | --- | --- |
| 対象 | exploratory.io に公開したコンテンツ（ノート、ダッシュボード、チャート、アナリティクス、データ） | 手元のパソコンの Exploratory Desktop にあるプロジェクト（公開していない変更を含む） |
| できること | 読み取り。ほかに、自分のアカウントへのページ（HTML ページ）の作成と、自分またはチームのページの更新・削除 | データフレーム、加工のステップ、チャート、アナリティクス、ノート、ダッシュボードの作成と編集 |
| 設定する場所 | AI アプリで、サーバーの URL を入力し、ブラウザーでサインインします | Exploratory Desktop の「システム設定」にある、プラグインのインストールカード |

- [Server](/ja/mcp/server) - exploratory.io に公開したコンテンツを読み取ります。ページ（HTML ページ）も作れます。
- [Desktop](/ja/mcp/desktop) - 手元のパソコンの Exploratory Desktop で、プロジェクトを作成・編集します。
