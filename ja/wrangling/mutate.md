「計算を作成」は、計算式や関数を使って新しい列を作る機能です。既存の列を計算結果で置き換えることもできます。計算式は計算エディタに入力します。

## 標準の計算を作成する

今回は1行が1注文の売上のデータを使用していきます。

![](images/ja/mutate-01.png)

売上を数量で割った「商品単価」の列を新しく作成したいです。

![](images/ja/mutate-02.png)

商品単価は以下の計算式で求められるようになっています。

``` text
商品単価 = 売上 / 数量
```

列ヘッダメニューから「計算を作成」の「標準」を選択します。

![](images/ja/mutate-03.png)

「計算を作成」のダイアログが表示され、計算エディタに計算式や関数を指定していくことができます。

![](images/ja/mutate-04.png)

また、Exploratoryで計算をする際には以下の演算子がサポートされています。

![](images/ja/mutate-05.png)

計算エディタ上で「タブキー」を押すことで、演算子の候補を表示できるようになっています。

![](images/ja/mutate-06.png)

計算エディタには以下のように指定をします。

``` text
売上 / 数量
```

![](images/ja/mutate-07.png)

新しく列を作成にチェックがついていれば、計算結果を求めたものを新しい列として作成ができます。今回は、列名に「商品単価」とつけます。

![](images/ja/mutate-08.png)

また、新しい列をどの列の後に作るかは「この列の後に作る」から指定ができます。今回は数量の後に作りたいため、「数量」を指定します。

![](images/ja/mutate-09.png)

実行することで、売上を数量で割った「商品単価」の列を作成できました。

![](images/ja/mutate-02.png)

商品単価の列の「i」をクリックすることで、サマリ情報を確認できます。

![](images/ja/mutate-10.png)

## 関数を使って計算する

先ほど求めた「商品単価」の列を小数第2位までの値に丸めたいとします。

![](images/ja/mutate-11.png)

列ヘッダメニューから「数値関数を使う」を選び、「四捨五入 (round)」を選択します。

![](images/ja/mutate-12.png)

計算を作成のダイアログが表示され、計算エディタには四捨五入ができる「round」関数が指定されています。

![](images/ja/mutate-13.png)

小数第2位までの値に丸めるため、引数には「digits = 2」と指定します。

![](images/ja/mutate-14.png)

実行することで、商品単価の列を小数第2位までの値に丸められました。

![](images/ja/mutate-15.png)

## 関数一覧

Exploratoryの中でどういった関数があるのか、関数の書き方について知りたいという方は「関数一覧」の機能をご使用ください。

計算を作成のダイアログの中で、「関数一覧」をクリックします。

![](images/ja/mutate-16.png)

関数一覧が表示され、この中でExploratoryでサポートされている豊富な関数を調べていくことができます。

![](images/ja/mutate-17.png)

日本語にも対応しているため、検索ボックスでキーワードを検索して、該当する関数を調べていくことも可能です。

![](images/ja/mutate-18.png)

さらには、使用したい関数があれば、「関数を挿入」または関数自体を「ダブルクリック」することで、計算エディタに関数を埋め込むことができるようになっています。

![](images/ja/mutate-19.png)

## 数値や文字列の列を新しく追加する

Exploratoryでは、裏でRを使用しているため、列を追加する際にはセルごとに指定するのではなく、列単位で一括で指定をすることとなっています。

### 数値

例えば、下記のように「送料」といった数値列を新しく列として追加をしたいとします。

![](images/ja/mutate-20.png)

列ヘッダメニューから「計算を作成」の「標準」を選択します。

![](images/ja/mutate-21.png)

計算を作成のダイアログが表示され、計算エディタには「売上」の列が指定されています。

![](images/ja/mutate-22.png)

計算エディタに今回は数値として「10」を入力します。数値の場合は、半角で入力する必要があります。

![](images/ja/mutate-23.png)

新しく列を作成にチェックをつけ、任意の列名をつけられたら実行ボタンをクリックします。

![](images/ja/mutate-24.png)

これによって数値列を新しく作ることができました。

![](images/ja/mutate-20.png)

### 文字列

次に、文字列型の列として下記のように「国」の列を作りたいとします。

![](images/ja/mutate-25.png)

列ヘッダメニューから「計算を作成」の「標準」を選択します。

![](images/ja/mutate-26.png)

計算を作成のダイアログが表示されるため、計算エディタには"Japan"と指定をします。文字列型の値を指定する場合、文字列の両端にダブルクォート（"）で囲う必要があります。

![](images/ja/mutate-27.png)

新しく列を作成にチェックをつけ、任意の列名をつけたら実行ボタンをクリックします。

![](images/ja/mutate-28.png)

これによって文字列型の列を新しく作ることができました。

![](images/ja/mutate-25.png)

## 複数の条件を組み合わせてフラグ列を作る

Exploratoryの「計算を作成」機能では、AND（かつ）やOR（または）といった論理演算子を組み合わせることで、複数の条件を元にTRUE/FALSEのフラグを持つ列を簡単に作成できます。「条件を元に計算、または値を置き換える」UIを使う方法に比べ、計算式を直接記述することでより簡単かつ複雑な条件設定が可能になります。

まず、1つの条件（年齢が40歳以上）を元にフラグ列を作成する方法を確認します。

年齢列のヘッダーメニューから「計算を作成」の「標準」を選択します。

![](images/ja/mutate-29.png)

計算エディターのダイアログが開いたら、計算式の入力欄にはあらかじめ「年齢」が入力されています。

入力欄の末尾で半角スペースを押すと、利用可能な演算子の候補が表示されます。

![](images/ja/mutate-30.png)

その中から「以上」を選択し、`年齢 >= 40`という形式で条件式を入力します。

![](images/ja/mutate-31.png)

新しい列名に「フラグ」を入力し、実行ボタンをクリックします。

![](images/ja/mutate-32.png)

これで年齢が40歳以上の行にはTRUE、それ以外の行にはFALSEが設定されたフラグ列が作成できました。

![](images/ja/mutate-33.png)

### ANDを使って複数条件のフラグ列を作成する

次に、「年齢が40歳以上」かつ「性別が男性」という2つの条件を組み合わせてフラグを立てる方法を説明します。

先程追加したステップのトークンをクリックして、計算エディターのダイアログを開きます。

![](images/ja/mutate-34.png)

計算式の入力欄に`年齢 >= 40`と入力した後に続けて`&`を入力すると、AND条件を追加できます。

![](images/ja/mutate-35.png)

「&」に続けて「性別」を入力し、演算子として「等しい」を選択すると値の候補が表示されるので、「男性」を選択し、`年齢 >= 40 & 性別 == "男性"`という計算式を完成させます。

![](images/ja/mutate-36.png)

実行ボタンをクリックすると、年齢が40歳以上かつ性別が男性の行にのみTRUEが設定され、どちらか一方でも条件を満たさない行はFALSEになります。

![](images/ja/mutate-37.png)

これで複数の条件をANDで組み合わせたフラグ列が作成できました。

### ORを使って「または」の条件を設定する

続いて、「または（OR）」の条件を設定する方法を説明します。

計算エディターのダイアログを開き、「&」の代わりに「\|」（縦棒・パイプ）を使用します。

![](images/ja/mutate-38.png)

「\|」はOR（または）を表す演算子で、例えば`年齢 >= 40 | 性別 == "男性"`と入力すると、年齢が40歳以上または性別が男性のいずれかを満たす行にTRUEが設定されます。

実行ボタンをクリックすると、いずれかの条件に合致する行にはTRUEが、年齢が40歳未満かつ性別が女性の行にのみFALSEが設定されていることが確認できます。

![](images/ja/mutate-39.png)

これでOR条件を使ったフラグ列が作成できました。

### ANDとORを組み合わせた複雑な条件を設定する

最後に、「年齢が40歳以上かつ男性、もしくは管理職」というANDとORを組み合わせた複雑な条件の設定方法を説明します。

計算エディターのダイアログを開き、まず`年齢 >= 40 & 性別 == "男性"`の部分を括弧でくくって1つのグループ条件とします。

![](images/ja/mutate-40.png)

次に`|`を入力してOR条件を追加し、続けて`管理職 == "はい"`と入力します。これにより`(年齢 >= 40 & 性別 == "男性") | 管理職 == "はい"`という計算式が完成します。

![](images/ja/mutate-41.png)

実行ボタンをクリックすると、例えば年齢が40歳以上で男性の行にはTRUEが設定され、管理職がはいになっている女性の行にも同様にTRUEが設定されていることが確認できます。

![](images/ja/mutate-42.png)

このように括弧を使ってANDとORを組み合わせることで、柔軟に複雑な条件を表現できます。これで複数条件を組み合わせた高度なフラグ列の作成ができました。
