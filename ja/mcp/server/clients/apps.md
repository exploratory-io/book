---
title: "AI ツールから追加する"
---

すでにお使いの AI ツールに、Exploratory のサーバーを追加します。どのアプリも、つなぐ先は同じです。初回に、ブラウザで Exploratory にサインインします。

```text
https://exploratory.io/mcp
```

<a id="apps"></a>

## アプリを選ぶ

- [Claude アプリ](claude.md) - Claude に、カスタムコネクタとして追加します
- [ChatGPT アプリ](chatgpt.md) - ChatGPT のデスクトップアプリに、MCP サーバーとして追加します（Web で使う場合の手順も、同じページにあります）
- [Antigravity](antigravity.md) - Antigravity にサーバーを登録します
- [Grok Bot](grok-bot.md) - Grok Bot のチャットでサーバーを追加します
- [Claude Code](claude-code.md) - Claude Code にサーバーを登録します
- [Codex](codex.md) - Codex にサーバーを登録します
- [Cursor](cursor.md) - Cursor にサーバーを登録します
- [そのほかのアプリ](other.md) - Streamable HTTP と OAuth に対応したクライアントです

アプリがブラウザを開けないときは、代わりに API キーで接続します。[API キーで接続する](../auth.md#apikey) を参照してください。
