---
title: "そのほかのアプリにつなぐ"
---

接続すると、AI から Exploratory に公開されたノートやデータを読めるようになります。ページ（HTML ページ）も作れます。Streamable HTTP と OAuth に対応した MCP クライアントなら、サーバー URL を登録してつなげます。
かかる時間は 5 分ほどです（クライアントによります）。Exploratory のアカウントと、対応した MCP クライアントを用意してください。

<a id="need"></a>

## 必要なもの

- Exploratory のアカウント
- Streamable HTTP（HTTP で MCP をやり取りする方式）と、OAuth（ブラウザでサインインして許可する仕組み）に対応した MCP クライアント
- クライアント ID と API キーは必要ありません。クライアントが自分で登録します。

<a id="steps"></a>

## 手順

### 登録してサインインする

設定の場所と書き方は、クライアントの説明を参照してください。

1. クライアントの MCP サーバーの設定に、次のサーバー URL を登録します。

   ```text
   https://exploratory.io/mcp
   ```

2. クライアントの案内に従って、ブラウザで Exploratory にサインインします。
3. アクセスを許可します。

### つながったことを確かめる

1. クライアントの新しいチャットで、次のように送信します。

   ```text
   接続した Exploratory Server で、閲覧できるコンテンツを最大 3 件、URL 付きで一覧して。見つからなければ、その旨を教えて。
   ```

コンテンツが URL 付きで表示されていれば、接続できています。結果が 0 件でも、認証や接続に失敗したとは限りません。見分け方は、[自分のコンテンツが出ない](/ja/mcp/server/troubleshooting#zero)を参照してください。

<a id="apikey"></a>

## API キーで接続する

クライアントがブラウザを開けないときは、API キーを使います。キーは、アカウント設定 \> API キーで作り、環境変数に入れて、クライアントにそこから Authorization: Bearer \<キー\> として送らせます。コマンドラインに鍵をそのまま打ったり、設定ファイルにそのまま書いたりすると、シェルの履歴やファイルに残ります。キーで読めるものは、[API キーで接続する](/ja/mcp/server/auth#apikey)を参照してください。

<a id="trouble"></a>

## トラブルシューティング

有効なトークンがない要求には、HTTP 401 が返ります。クライアントの手順で、サインインし直してください。

- [データと権限](/ja/mcp/server/data#auth) - 認証の仕組みとメタデータの URL です。

- [トラブルシューティング](/ja/mcp/server/troubleshooting) - Server の MCP 全体の、症状ごとの対処です。

<a id="remove"></a>

## 接続を解除する

クライアントの設定から、登録した名前（例: exploratory-server）を削除します。

登録を解除しても、アクセスの許可は残ります。許可も取り消すには、exploratory.io のアカウント設定の「接続中のAIアプリ」から、クライアントを解除します。
