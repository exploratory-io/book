---
title: "データと権限"
---

どの権限で動作するか、何を読み取るか、Exploratory が何を記録するかを説明します。

<a id="who"></a>

## 実行されるユーザー

Server MCP の呼び出しは、サインインしたユーザーとして実行されます。そのユーザーが exploratory.io で閲覧できる範囲を超えることはありません。読み取るのは、公開されたコンテンツのみです。書き込むのはページ（HTML ページ）だけで、自分のアカウントにページを作り、自分またはチームのページを更新・削除します。

<a id="publisher"></a>

## 公開した人ができること

公開した人は、公開されたコンテンツごとに、MCP からのアクセスを止められます。データの行を非公開にすることもできます。その場合も、要約は共有できます。

<a id="records"></a>

## Exploratory が記録するもの

この MCP サーバーへの呼び出しについて、Exploratory Server は次のものを記録します。コマンドラインの expl server でも同様です。

トークンは、アクセス許可を表す文字列です。ハッシュは、元の文字列をそのまま保存せず照合するための値です。

- トークンと API キー: 平文ではなくハッシュで保存し、作成日時、有効期限、最終使用日時を記録します。トークンは「接続中のAIアプリ」で、API キーはアカウント設定 \> API キーで、確認・取り消しできます。
- データアクセスログ: アイテム、ユーザー ID とメールアドレス、経路、サインインの方法（ブラウザまたは API キー）と API キーの名前、操作、クライアント名、IP アドレス、結果とエラーコード、処理時間。保持期間は既定で 90 日です（サーバーの設定で 1〜400 日）。
- サーバーのログ: 道具の呼び出しごとの記録（メールアドレス、クライアント、結果、行数、処理時間）と、トークンの作成・削除。
- 失敗した呼び出しのエラー: 時刻、道具の呼び出し、エラーの内容を、製品の改善のために収集します。

- [Exploratory のプライバシーポリシー](https://exploratory.io/privacy) - データの取り扱いに関する方針を確認します。

<a id="provider"></a>

## AI の提供元へ渡るもの

道具が返すもの（行、列名、チャートの画像、エラー）は、会話の一部になります。使っている AI の提供元（例: Anthropic、OpenAI、Google、xAI）へ、その提供元の規約のもとで送られます。その提供元へ送ってはいけないデータには、この接続を使わないでください。

<a id="auth"></a>

## 呼び出しの認証の仕組み

クライアントを自分で作る人や、設定を確認したい人向けです。

| 項目 | 値 |
| --- | --- |
| 通信方式 | Streamable HTTP、ステートレス（POST のみ。GET と DELETE は 405） |
| 登録 | クライアントは Dynamic Client Registration か Client ID Metadata Document で登録（どちらも、クライアントが自分を登録する方法） |
| メタデータ | [https://exploratory.io/.well-known/oauth-protected-resource/mcp](https://exploratory.io/.well-known/oauth-protected-resource/mcp)、[https://exploratory.io/.well-known/oauth-authorization-server](https://exploratory.io/.well-known/oauth-authorization-server) |

有効なトークンがない呼び出しには、HTTP 401 が返り、WWW-Authenticate ヘッダーが保護リソースのメタデータを指します。クライアントはこれを参照して、サインインを開始します。

失敗したキーには、WWW-Authenticate: Bearer error="…", error_description="…" つきの 401 または 403 が返ります。上の 401 と違い、このヘッダーには resource_metadata がないので、固定のヘッダーを送るクライアントがサインインを始めることはありません。同じアドレスから（IPv4 は同じアドレス、IPv6 は同じ /64 の範囲で数えます）、15 分のうちに 30 回を超えて拒否されたキーが送られると、429 になります。

初回のサインインでは、同意画面が出ます。同意画面には「設定 > 接続済みアプリ」で取り消せると書かれています。これはアカウント設定にリンクしていて、そこでの節の名前は「接続中のAIアプリ」です（[接続を解除する](#disconnect)を参照）。401 のあとでサインインし直す方法は、[トラブルシューティング](/ja/mcp/server/troubleshooting#signin) にあります。

<a id="disconnect"></a>

## 接続を解除する

Server MCP の接続を解除するときは、exploratory.io のアカウント設定の「接続中のAIアプリ」から、クライアントを取り消します。クライアントの設定から登録を削除しただけでは、アクセスの許可は残ります。API キーを止めるには、同じアカウント設定の「API キー」で取り消します。

- [AI ツールから追加する](/ja/mcp/server/clients/apps) - クライアントごとの、登録を解除する手順です。
