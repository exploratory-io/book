Desktop の MCP で表示されるメッセージと、その対処です。

<a id="check"></a>

## まず状態を確かめる

接続できているかを、[AI ツールで確かめる](/ja/mcp/desktop/install#check)の手順で確かめます。つながらないときは、下の表で、表示された内容を探します。

<a id="contact"></a>

## 問い合わせるとき

support@exploratory.io へ、次を送ってください。Exploratory Desktop のバージョン、AI ツールの名前とバージョン、行った操作、表示されたエラーの文です。トークンや API キーは伏せてください。

<a id="trouble"></a>

## トラブルシューティング

| 表示される内容 | 対処 |
| --- | --- |
| exploratory-mcp が見つからない | MCP をオンにした Exploratory Desktop v17 以降を起動します。コマンドはアプリの起動時に自動で入ります。そのあと、AI ツールを起動し直します。 |
| AI ツールから exploratory-mcp が見つからない（macOS） | Exploratory をディスクイメージから開いています。/Applications か \~/Applications に移して起動し直すと、起動時にコマンドが入ります。 |
| カードに「インストールできませんでした。」と表示される | 「詳細」にマウスを載せて、出力を確かめます。理由の文に従って直し、「もう一度試す」を選びます。詳しくは [プラグインのインストール](/ja/mcp/desktop/install#failure) を参照してください。 |
| 別の場所から登録された exploratory があります（…）。「…」で削除してから、もう一度「インストール」を押してください。 | メッセージに出ているコマンドで削除してから、もう一度「インストール」を選びます。 |
| 組織の設定で、このマーケットプレイスが許可されていない可能性があります。管理者に確認してください。 | 管理者に確認します。 |
| Claude Code のフックで node が見つからない | Node.js を入れて、node を PATH に通します。 |
| プラグインの確認が呼び出しを止める（例: 画像を頼んでいないので get_note_image や get_dashboard_image が止められる）、制限に達する、承認を求められる | [制限とエラー](/ja/mcp/desktop/limits)を参照してください。画像が必要なときは、依頼の中で「画像」や「スクリーンショット」と頼みます。 |
| 作成や変更の呼び出しが PERMISSION_DENIED で断られる | システム設定 \> MCP / CLI で「作成、変更、削除を許可する」をオンにして「保存」を選びます。[制限とエラー](/ja/mcp/desktop/limits)を参照してください。 |
| 承認の画面で「許可しない」を選んだ | 5 分たってからもう一度接続すると、画面がもう一度出ます。[制限とエラー](/ja/mcp/desktop/limits)を参照してください。 |
| Desktop の MCP が想定どおりに動かない | Exploratory Desktop にサインインしているかを確認します。 |
