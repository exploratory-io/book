Desktop の MCP で、何が送られ、何が記録されるかを説明します。確認が入る場面と設定は、[許可の範囲と設定](/ja/mcp/desktop/permissions)にあります。

<a id="privacy"></a>

## 送られるものと記録されるもの

- Desktop の MCP は、お使いのコンピューターで動きます。アプリを通して、手元のプロジェクトの内容を読み、編集します。
- 道具が返す内容（行、列名、チャートの画像、エラー）は、会話の一部になります。AI の提供元に、その提供元の規約に従って送られます。その提供元に送ってはいけないデータには使わないでください。
- Desktop は、道具の呼び出しごとの記録（道具の名前、引数の名前（値は含まない）、結果、処理時間）をコンピューターの中に保存し、90 日で削除します。
- Exploratory Desktop は、Desktop の MCP の道具を 1 回呼び出すたびに、サインインしている exploratory.io のサーバーへ、利用記録を 1 件送ります。記録には、道具の名前と引数（入力した数式や値が入ることがあります）、成功か失敗か（失敗のときはエラーの種類とメッセージ）、結果の大きさ（内容は含みません）、処理時間、Desktop のバージョン、AI ツールの名前とバージョン、セッションとアイテムの ID が入ります。送られるのは、サインインしていて、AI 機能がオンのときだけです。ローカルのデータカタログの道具では送りません。
