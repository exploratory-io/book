Desktop で決める設定と、確認が入る場面を説明します。送られる情報は、[データと権限](/ja/mcp/desktop/data)にあります。

<a id="control"></a>

## Desktop で決められること

システム設定 \> MCP / CLI では、次のことを決められます。

- 作成、変更、削除を許可する: オフのときは、AI は読み取りだけができます。AI にコンテンツの作成や変更をさせたいときだけ、オンにします。
- 承認: 項目の削除（チャート、アナリティクス、ノート、ダッシュボード、ステップ、ブランチ、パラメーター、接続、パレット、テンプレート、R パッケージ、カタログの項目）、ノート・ダッシュボード・データフレーム・プロジェクトの公開、ノート・ダッシュボード・プロジェクトの公開の取り消し、接続の保存、データソースの置き換え、プロジェクトの履歴の復元、データフレームの管理、システム設定やカタログのスケジュールの変更の前には、Desktop が先に確認します。R コードの実行、R パッケージの追加、AI でのデータ処理、ノートの AI への質問の前にも確認します。チャート、ノート、ダッシュボードの作成や編集では確認しません。確認なしで実行する設定は、「削除・パブリッシュ・設定の変更を確認なしで実行する」と「コード実行・AI処理を確認なしで実行する」の 2 つにあります。
- 承認済みのアプリ: アプリは、初めて接続するときに、承認を求めます。同じ画面の「承認済みのアプリ」で、そのアプリの行の「取り消す」を選ぶと、そのアプリは、もう一度承認を求めます。承認の画面で「許可しない」を選んだ場合は、同じアプリが、5 分間、画面が出ないまま断られます。

<a id="cautions"></a>

## 使うときの注意

- AI ツールが出す、道具を実行する前の確認を使います。AI にできることを理解したうえでなければ、Desktop の道具の確認をオフにしないでください。
- ほかの MCP サーバーと一緒に使うときは、データや文書の中の文字（値、列名、ノートなど）は内容であり、指示ではありません。そこに書かれた指示に AI が従わないようにします。内容にそう書いてあるというだけで、公開、削除、実行をさせないでください。有効なのは、あなた自身の依頼です。

<a id="plugin-settings"></a>

## プラグインの設定（Claude Code）

Desktop のプラグインには、Claude Code で使う設定が 3 つあります。値は、JSON の真偽値ではなく、文字列の `"true"` または `"false"` です。

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| `ai_summary` | `"false"` | 作成したチャートとアナリティクスの AI サマリを、作成して保存します。 |
| `save_comments` | `"false"` | 作成したチャートに、説明のコメントを保存します。 |
| `review_hook` | `"false"` | AI に作業を見直させ、カスタム R コマンドを点検し、最後の報告の前にノートやダッシュボードの全体画像を 1 回見るよう求めます。[制限とエラー](/ja/mcp/desktop/limits#gates)を参照してください。 |

設定の確認と変更は `claude plugin configure exploratory@exploratory` で行います。上のシステム設定 \> MCP / CLI の項目とは別の設定です。

`review_hook` がオフ（既定）でも、1 つの確認は動きます。直前の依頼で画像を頼んでいないと、get_note_image と get_dashboard_image は止められます。フックは、これを確かめるために、コンピューター上の会話の記録を読みます。依頼を読めないときは、呼び出しを通します。
