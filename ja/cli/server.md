expl server は、exploratory.io に公開されたノート、ダッシュボード、データを、ターミナルから読むコマンドです。

<a id="target"></a>

## 対象

> このページは Exploratory Server のみを対象にします。Exploratory Desktop については、[CLI Desktop](/ja/cli/desktop) と [MCP Desktop](/ja/mcp/desktop) を参照してください。
>
> AI ツールからつなぐときは、[MCP Server](/ja/mcp/server) を参照してください。

<a id="start"></a>

## 読み進めるには

- [はじめる](/ja/cli/server/get-started) - インストールとサインインをして、データを探して読むところまで進めます。[インストール](/ja/cli/server/install)、[サインイン](/ja/cli/server/login)、[API キー](/ja/cli/server/token)のページもあります。
- [使い方](/ja/cli/server/use) - やりたいことから、使うコマンドと手順のページを探します。
- [リファレンス](/ja/cli/server/reference) - コマンド、共通フラグ、終了コードとエラー、データと権限を調べます。
- [トラブルシューティング](/ja/cli/server/troubleshooting) - 症状から対処を探します。

<a id="ai"></a>

## AI から使うなら

- [AI エージェントから使う](/ja/cli/server/guides/agents) - シェルを使える AI に、expl の使い方を教えます。
- [MCP Server](/ja/mcp/server) - AI ツールから、公開されたコンテンツを読みます。
