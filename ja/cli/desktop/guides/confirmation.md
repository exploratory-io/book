---
title: "確認と時間のかかる操作"
---

取り消しにくい操作は、実行の前に確認します。時間のかかる操作は、既定では終わるまで待ちます。

<a id="confirm"></a>

## 取り消しにくい操作の確認

リスクが HIGH の操作（公開、削除など）は、実行の前に確認します。どの操作かは、expl tools list の RISK の列で分かります。

| 状況 | 動き |
| --- | --- |
| ターミナルで `--yes` なし | Continue? \[y/N\] と聞きます。y または yes（大文字小文字は区別しません）で実行し、それ以外は中止します（終了コード 1）。 |
| ターミナル以外（スクリプト、CI、AI エージェント、出力をファイルやパイプに向けたとき）で `--yes` なし | 何も実行せず、終了コード 2 で終了します。 |
| `--yes` あり | 確認せずに実行します。 |

`--yes`（または聞かれたときの y）は、利用者が確認したことになります。

<a id="wait"></a>

## 時間のかかる操作

既定では、終わるまで待ちます。待っている間、進捗を標準エラーに出します。`--timeout <秒>` を付けると、全体の上限を決められます。

`--timeout` を指定しない場合、応答は最長 120 秒待ち、時間のかかる操作の完了待ちには全体の上限がありません。

`--no-wait` を付けると、execution_id と operation_id を表示してすぐに終わります。あとで次のコマンドで状態を確認します。

```sh
expl execution get <execution_id> --operation-id <operation_id>
```

\<execution_id\> と \<operation_id\> は、`--no-wait` が表示した値に置き換えます。

`--timeout` を過ぎると、確認方法を示して終了コード 1 で終了します（処理は続きます）。待っている間に Ctrl+C を押すと、処理の取り消しを要求して終わります（終了コード 130）。取り消しの要求が失敗する場合があります。必要なときは、expl execution get で状態を確かめます。
