---
title: "終了コードとエラー"
---

expl は、終わるときに終了コードを返します。スクリプトや CI は、この数字で結果を判断できます。

<a id="codes"></a>

## 終了コードの一覧

| コード | 意味 |
| --- | --- |
| 0 | 成功 |
| 1 | 操作が失敗しました。Desktop では、確認を断ったとき、タイムアウト、2 分以内に承認の答えが無かったとき（PAIRING_PENDING）も含みます。 |
| 2 | 使い方が正しくありません。生成されたコマンドの未知のフラグ、読めない JSON、ターミナル以外での `--yes` の付け忘れなどです。 |
| 3 | Desktop または Server に接続できません。Server では、ネットワークや HTML のエラーページなどです。 |
| 4 | 認証、承認、権限のエラーです。Desktop では、サインインしていない、接続が承認されていない、CLI がオフ、操作が許可されていない、のいずれかです。Server では、サインインしていない、またはトークンや API キーが拒否されたとき（間違い、期限切れ、取り消し、管理者による制限）です。 |
| 130 | Ctrl+C で中断しました |

出力先のパイプが閉じられた場合（expl ... | head -1 など）は、エラーではなく、終了コード 0 で終了します。

<a id="action"></a>

## 3 と 4 のとき

| コード | 対処 |
| --- | --- |
| 3 | Desktop を使っているときは、Exploratory Desktop を起動して、もう一度実行します。Server を使っているときは、通信を確認して、もう一度実行します。 |
| 4 | Desktop を使っているときは、メッセージの末尾の括弧内のコードで、どの場合か分かります（下の表を参照）。Server を使っているときは、expl server login を実行します。API キーを使っているときは、間違い・期限切れ・取り消しなら、アカウント設定 \> API キーで新しいキーを作ります。API キーが無効、または IP アドレスが許可されていないというメッセージなら、管理者に確認します。EXPL_SERVER_TOKEN が設定されている状態で保存したログイン情報に切り替えるときは、保存したログイン情報より先に EXPL_SERVER_TOKEN が使われるので、先に unset EXPL_SERVER_TOKEN を実行してください。 |

終了コード 4 のメッセージの末尾のコードで、対処が分かります。

| メッセージのコード | 対処 |
| --- | --- |
| NOT_LOGGED_IN | Server のみ。expl server login を実行します。 |
| NOT_SIGNED_IN | Exploratory Desktop にサインインします。 |
| UNAUTHORIZED | Desktop の場合: もう一度実行します。Exploratory Desktop が接続の承認を求めます。Desktop の[はじめる](/ja/cli/desktop/get-started#steps)を参照してください。Server の場合: API キーが拒否されました（間違い・期限切れ・取り消し）。アカウント設定 \> API キーで新しいキーを作り、EXPL_SERVER_TOKEN に設定するか、`expl server login --with-token` を実行します。 |
| PAIRING_REQUIRED | Exploratory Desktop の承認の画面で、この接続が断られました（短い時間に要求が多すぎたときも、このコードになります）。断ってから 5 分間は、もう一度実行しても画面は出ずに断られます。5 分たってからもう一度実行し、画面で許可します。 |
| CHANNEL_DISABLED | システム設定 > MCP / CLI で、「CLI」のカードのスイッチをオンにして「保存」を選びます。 |
| PERMISSION_DENIED | Desktop の場合: この接続では、その操作は許可されていません。作成、変更、削除の操作なら、システム設定 > MCP / CLI の「作成、変更、削除を許可する」がオンになっているかを確認します。Server の場合: 管理者が API キーを無効にしているか、接続元の IP アドレスを制限しています。管理者に確認するか、expl server login でサインインします。 |

症状から対処を探すには、[トラブルシューティング](/ja/cli/desktop/troubleshooting)を参照してください。
