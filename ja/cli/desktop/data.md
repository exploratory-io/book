## 送信・記録されるもの

コマンドは、コンピューターの中の通信で Desktop に送られます。Desktop は、道具を呼び出すたびに、道具の名前、引数の名前（値は含みません）、結果、処理時間を記録して、コンピューターの中に保存し、90 日で削除します。

また、サインインしていて AI 機能がオンのときは、MCP Desktop と同じく、道具の呼び出しごとに利用記録を 1 件、サインインしている exploratory.io のサーバーへ送ります（ローカルのデータカタログの道具では送りません）。記録には、道具の名前と引数（入力した式や値が入ることがあります）、成功したかどうかとエラーの種類・メッセージ、結果の大きさ（中身は含みません）、処理時間、Desktop のバージョン、クライアントの名前とバージョン、セッションとアイテムの ID が含まれます。

expl 自体は、利用状況の計測を送りません。

MCP Desktop の記録については、[データと権限](/ja/mcp/desktop/data)も参照してください。
