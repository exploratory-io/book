<a id="privacy"></a>

## 送信・記録されるもの

expl 自体は、利用状況の計測を送りません。通信する相手は、お使いのコンピューターの Exploratory Desktop と、サインインした Exploratory Server だけです。

トークン、アクセスの記録、ログ、エラーは、[Exploratory Server が記録するもの](../../mcp/server/data.md#records)を参照してください。API キーとログインの記録は、[API キー](token.md#records)と[サインイン](login.md#records)のページにもあります。Desktop が記録するものは、[Desktop が記録するもの](../desktop/data.md#records)を参照してください。

誰の権限で動くかは、MCP Server の[データと権限](../../mcp/server/data.md)を参照してください。
