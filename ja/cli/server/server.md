# Exploratory CLI: Server

expl server は、exploratory.io に公開されたノート、ダッシュボード、データを、ターミナルから読むコマンドです。

<a id="target"></a>

## 対象

> このページは Exploratory Server のみを対象にします。Exploratory Desktop については、[CLI Desktop](../desktop/desktop.md) と [MCP Desktop](../../mcp/desktop/desktop.md) を参照してください。
>
> AI ツールからつなぐときは、[MCP Server](../../mcp/server/server.md) を参照してください。

<a id="start"></a>

## 読み進めるには

- [はじめる](get-started.md) - インストールとサインインをして、データを探して読むところまで進めます。[インストール](install.md)、[サインイン](login.md)、[API キー](token.md)のページもあります。
- [使い方](use.md) - やりたいことから、使うコマンドと手順のページを探します。
- [リファレンス](reference.md) - コマンド、共通フラグ、終了コードとエラー、データと権限を調べます。
- [トラブルシューティング](troubleshooting.md) - 症状から対処を探します。

<a id="ai"></a>

## AI から使うなら

- [AI エージェントから使う](guides/agents.md) - シェルを使える AI に、expl の使い方を教えます。
- [MCP Server](../../mcp/server/server.md) - AI ツールから、公開されたコンテンツを読みます。
